# 🍔 Landing Page FooD PeeK

Landing page de uma hamburgueria fictícia chamada **FooD PeeK**, criada para praticar HTML e CSS na construção de uma página de apresentação com foco visual.

🔗 **Online:** [brenoryan-dev.github.io/Landing-page-hamburgue](https://brenoryan-dev.github.io/Landing-page-hamburgue/)

## Sobre o projeto

Projeto de estudo que reproduz o estilo de uma landing page de restaurante: cabeçalho com menu, título chamativo, texto de apresentação, botão de chamada para ação e uma imagem de destaque de hambúrguer.

## Estrutura da página

- **Cabeçalho:** logotipo e menu de navegação (Home, About, Menu, Contact)
- **Seção principal (hero):**
  - Título de boas-vindas
  - Frase de destaque
  - Texto de apresentação
  - Botão **"order yours"**
  - Imagem de hambúrguer

## Tecnologias utilizadas

- HTML5
- CSS3
- GitHub Pages (hospedagem)

## Como rodar localmente

1. Clone o repositório:

```bash
git clone https://github.com/brenoryan-dev/Landing-page-hamburgue.git
```

2. Entre na pasta:

```bash
cd Landing-page-hamburgue
```

3. Abra o `index.html` no navegador, ou use a extensão **Live Server** do VS Code.
